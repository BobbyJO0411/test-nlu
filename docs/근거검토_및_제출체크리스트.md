# 근거 검토 및 제출 준비 체크리스트

## 자료 출처와 적용 범위
사용자 제공 PDF는 ‘상표심사기준’, 표지 기준일 2025.12.10, 575페이지이다. 원본 해시는 data/source_manifest.json에 기록했다. Git에는 원본 전체 PDF 대신 출처 식별정보와 필요한 페이지 발췌를 저장한다. data/source_excerpts.json의 pdf_page는 뷰어의 1부터 시작하는 물리 페이지이며 인쇄 쪽수와 구분한다. 일부 인쇄 쪽수는 자동 추출이 되지 않아 null이다.

정답답변은 이 문서에서 작성한 기준답변 초안이며 실제 실무자의 승인 정답셋이 아니다. 각 응답의 source_ids를 통해 PDF 원문과 대조할 수 있다. 발췌 페이지가 모든 답변 문장의 유일한 법적 근거를 뜻하지는 않는다.

## 특히 확인할 사항
- 이의신청: 첨부 PDF 387·390페이지 등에 기간 표현이 있으나 현행 법령, 시행일·경과규정과 사건 공고일을 별도로 확인한다. 현재 응답에서는 특정 일수로 마감일을 단정하지 않는다.
- 수수료: PDF 64·65페이지는 미납 절차 보정, 117·349페이지는 등록료 납부와 절차의 관련성을 설명한다. 현재 관납료 금액·감면·대리인 보수의 가격표를 제공하지 않는다. 정확한 요율 및 상품 수 산정 방식은 최신 공식 자료로 추가 검토해야 한다.
- 거절결정: 재심사 청구 요건·시기 및 불복심판 가능성을 개별 사건에 대조한다. 일반 통지와 최종 결정의 단계 차이를 유지한다.
- 공존동의: 동일 표장·동일 상품 제외, 권리자·서류 적정성, 타 거절 사유가 남는지를 확인한다.
- 식별력: 보통명칭에 사용에 의한 식별력 예외를 무조건 적용하지 않는다. 각 조항의 적용 대상과 지정상품 관계를 확인한다.
- 상표유사·상품유사: 상표 257~261페이지, 상품 268페이지 등을 확인하며 분류 번호만으로 판단하지 않는다.
- 운영 현실성: 질의 유형 비중은 균등 4건씩의 설계이다. 실제 고객 분포에서 도출된 비율이 아니다. 수수료 등 실제 요구 금액에 대해 안내만으로 성공으로 인정할지 전문가가 사전에 정의한다.

## 제출 전 필수 완료
- [ ] 시험기관 확인요청서(docs/시험기관_확인요청서.md) 발송 및 14개 질문 회신 기록
- [ ] 승인된 모델(제안: nlpai-lab/KoE5)이 시험계획의 E5-Ko 또는 KoBERT 요구에 부합한다는 기관 확인
- [ ] 하이브리드 검색(β>0)과 템플릿 대표 질문 다중 등록의 허용 여부 확인. 불허 시 β=0 설정으로 재실행
- [ ] 실제 고객 질의 추출·익명화·층화 추출(docs/실질의_수집_및_승인절차.md) 및 사람의 익명화 검토
- [ ] 시험 질의가 템플릿·대표 질문·검색 가중치 조정에 쓰이지 않았다는 기록(개발셋 분리)
- [ ] 템플릿 DB 전문가 검토 워크북(템플릿DB_전문가검토.xlsx) 작성·반영, 모든 템플릿 approved(scripts/apply_template_review.py)
- [ ] 정답셋·템플릿·대표 질문·검색 설정의 실무자/상담 경험자 사전 검토 및 서명 승인(data/approval.json)
- [ ] 최신 법령·기한·수수료·경과규정 확인일과 근거 기록
- [ ] 승인 모델로 100건 실행: 추천 원문·상위 후보·해시·Git 커밋(git_worktree_clean=true) 기록
- [ ] 기존 제품에 모듈을 연결했다면 제품 버전과 실제 호출 경로 검증
- [ ] 불일치 처리 규칙(협의 또는 다수결)을 평가 시작 전에 확정하고 approved_decision_rule에 기록
- [ ] 서로 독립된 실제 A·B의 100건 이진 판정과 5개 정량 설문 기록
- [ ] 협의: 불일치 건의 최종 판정·근거·참여자·일시·서명 / 다수결: 제3평가자 C의 블라인드 판정 원본
- [ ] 최종 100건 완전성과 원문 무결성 확인 및 집계 검증(submission_candidate=true)
- [ ] ISO 절 번호·지표 코드(FCr-1-G, X=1−A/B)·측정 단위 및 산식 대응 원문 확인
- [ ] 사전 합격 기준과 시험기관 보고 형식 확정
- [ ] 모의 평가 파일, 문자 baseline 결과, 개발셋 결과를 실제 성적 증빙에서 제외

가상 A·B 시트와 모의요약은 별첨의 계산 예제로만 표시한다. 실제 평가·승인·시험 수행을 증명하는 자료로 사용할 수 없다.
