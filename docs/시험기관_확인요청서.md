# 시험기관 사전 확인 요청서 — NLU 기반 반자동 응답 추천 기능 적합도

문서 상태: 발송용 초안. 작성일 2026-11-06. 기관의 회신 내용과 회신 문서 번호를 data/approval.json의 agency_model_acceptance_reference, sampling_approval_reference에 기록한다. 회신 전에는 어떤 항목도 확정된 것으로 표시하지 않는다.

## 1. 시험 대상 요약
- 기능: 고객 질의를 문장 임베딩으로 변환해 사전 등록된 응답 템플릿 30개 중 상위 3개 후보를 추출하고, 1순위 템플릿 원문을 그대로 추천한다. 사람이 검토한 뒤 전송하는 반자동 흐름이며 답변 문장을 새로 생성하지 않는다.
- 측정: 질의 100건의 추천 응답을 평가자가 성공/실패로 판정한다. 적합도(%) = 성공 응답 수 ÷ 전체 응답 수 × 100, 합의율(%) = 합의 응답 수 ÷ 전체 응답 수 × 100.

## 2. 확인 요청 사항

### 2.1 모델 (실행 환경: E5-Ko 또는 KoBERT 기반 문장 임베딩 모델)
제안 모델: nlpai-lab/KoE5, 커밋 237b580aea358e3042fcf5baf78124c33c3afd16, MIT 라이선스, 1024차원, 최대 512토큰. intfloat/multilingual-e5-large를 한국어 triplet 데이터(ko-triplet-v1.0)로 미세조정한 공개 모델이다. 본 프로젝트에서 추가 학습하지 않았다.
- 질문 1: 이 모델이 시험계획의 ‘E5-Ko 기반 문장 임베딩 모델’ 요건을 충족하는가?
- 질문 2: 충족하지 않는다면 허용되는 모델 ID(또는 KoBERT 계열 특정 모델)를 지정해 줄 수 있는가?
- 참고: 비교용으로 dragonkue/multilingual-e5-small-ko-v2, intfloat/multilingual-e5-small을 함께 개발셋에서 측정했다. 성적 산출에는 승인된 한 모델만 사용한다.

### 2.2 검색 방식
1순위 템플릿 점수 = α × (질의와 템플릿 대표 질문들 간 최대 코사인 유사도) + (1−α) × (질의와 템플릿 본문 간 코사인 유사도) + β × (문자 n-gram TF-IDF 유사도). α, β는 시험셋과 분리된 개발셋 90건에서만 정했다.
- 질문 3: 임베딩 점수에 문자 기반 보조 점수를 더하는 하이브리드 방식이 ‘E5-Ko 기반’ 시험 대상으로 인정되는가? 인정되지 않으면 β=0(임베딩 단독)으로 시험한다.
- 질문 4: 템플릿마다 대표 질문 여러 개를 등록하는 방식(템플릿 DB의 일부로 승인 대상)이 허용되는가?

### 2.3 질의 표본 (실사용 환경을 반영한 고객 질의 100건)
- 질문 5: 실제 고객 질의를 익명화해 추출한 100건이 필요한가, 또는 전문가가 승인한 합성 질의도 허용되는가?
- 질문 6: 유형 비중은 실제 접수 분포에 비례해야 하는가(비례 층화 추출), 아니면 유형별 균등 배분이 허용되는가?
- 질문 7: 템플릿·검색 설정을 정할 때 사용한 자료와 시험 질의를 분리해야 한다는 조건(홀드아웃)의 확인 방식은 무엇인가?

### 2.4 평가자와 불일치 처리
- 질문 8: 평가자 자격(실무자, 변리사, 고객 상담자)의 확인 방식과 필요한 증빙은 무엇인가?
- 질문 9: 불일치 시 ‘다수결’과 ‘협의’ 중 어느 쪽을 적용하는가? 다수결이면 제3평가자 C가 A/B 불일치 건만 블라인드로 판정하는 방식이 허용되는가, 아니면 3인이 100건 모두 평가해야 하는가?
- 질문 10: 합의율의 분자 ‘합의 응답 수’는 협의·다수결 이전 최초 A=B 일치 건수로 해석하는 것이 맞는가? (현재 구현: 최초 일치 기준, 협의 결과로 덮어쓰지 않음)

### 2.5 지표 표기 (ISO/IEC 25023:2016, 8.2.2 Functional correctness measures, FCr-1-G)
- 질문 11: FCr-1-G를 X = 1 − A/B(A = 부정확한 응답 수, B = 평가한 응답 수)로 계산하고, 이 값이 적합도(성공 ÷ 전체)와 같음을 성적서에 함께 적는 방식이 맞는가? 본 프로젝트는 표준 원문을 열람해 절 번호와 코드를 대조하지 못했다.
- 질문 12: 합의율은 ISO 지표가 아닌 보조 신뢰성 지표로 표기하는 것이 맞는가?

### 2.6 합격 기준과 보고 형식
- 질문 13: 적합도와 합의율의 합격 기준(목표 %)이 있는가? 없다면 결과만 보고하는가?
- 질문 14: 성적서에 첨부할 증빙(정량 설문 원본, 서명 승인서, 실행 로그, 해시 목록 등)의 형식이 정해져 있는가?
