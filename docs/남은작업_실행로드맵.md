# 자체 시험 실행 로드맵

작성 2026-11-10, 개정 2026-11-11(자체 시험으로 전환, 합격 기준 적합도 80% 이상). 상세 기준은 시험방법서.md를 따른다.

## 1. 사전 준비 (담당: 시험 담당자, 실무자)
- 평가자 지정: A 민원·상표 상담 실무자, B 변리사 또는 고객 상담자. 서로 다른 사람. 다수결을 쓰면 제3평가자 C도 지정한다.
- 불일치 처리 규칙(협의 또는 다수결)을 평가 전에 정한다.
- 템플릿 DB 검토: 템플릿DB_전문가검토.xlsx 작성 → `python scripts/apply_template_review.py --workbook <파일> --write`
- 정답셋 승인: 질의 100건과 기준답변을 실무자가 검토하고 `python scripts/approval_hashes.py --output data/approval.draft.json`로 만든 초안에 검토자·역할·승인일을 채워 data/approval.json으로 저장한다.
- 템플릿이나 질의를 고쳤다면 커밋한 뒤 다음 단계로 간다.

## 2. 실행 (담당: 시험 담당자)
- `python scripts/self_test.py prepare`
- 산출: artifacts/self_test/<실행ID>/ 의 평가자A.xlsx, 평가자B.xlsx, manifest.json, recommendations.json, 실행요약.json

## 3. 독립 평가 (담당: 평가자 A, B)
- 각자 자기 파일만 받아 100건 판정(success/failure), 설문 5개(1~5점), 평가근거, 성명, 역할·자격, 평가일시를 입력한다.

## 4. 불일치 처리 (담당: A·B 또는 C)
- `python scripts/self_test.py resolve --run-dir artifacts/self_test/<실행ID> --a <A파일> --b <B파일>`
- 협의: 협의결과.csv의 final, resolution_reason, resolution_date, participants 입력
- 다수결: `--decision-rule majority`로 평가자C.xlsx 생성 후 C가 입력

## 5. 집계와 판정 (담당: 시험 담당자)
- `python scripts/self_test.py score --run-dir artifacts/self_test/<실행ID> --a <A파일> --b <B파일>` (다수결은 `--decision-rule majority`)
- 산출: 시험결과서.docx, 시험결과_상세.xlsx, 시험결과.json
- 적합도 80% 이상이면 합격. 미만이면 불합격으로 그대로 기록한다.

## 6. 제출
- 시험방법서.docx와 결과 폴더의 시험결과서.docx를 제출하고, 평가 원본과 실행 기록을 첨부·보관한다.
