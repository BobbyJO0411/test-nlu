# 자체 시험 실행 가이드 (Windows PC)

작성 2026-11-17. 시험방법서의 절차를 PC에서 그대로 따라 할 수 있도록 명령 순서대로 정리한 문서이다. 아래 경로는 PC의 C:\Users\jwcho\workspaces 기준이다.

## 0. 준비물
- 작업 폴더: workspaces\test-nlu (코드), workspaces\nlu-venv (Python 3.12 가상환경), workspaces\nlu-models\nlpai-lab__KoE5 (검증된 모델)
- 위 세 폴더는 이미 PC에 있다. 새 PC라면 `powershell -ExecutionPolicy Bypass -File scripts\install.ps1`로 한 번에 만든다.
- 평가자: A(상표 민원 실무자), B(변리사 또는 고객 상담자). 다수결을 쓰면 제3평가자 C.

## 1. 최신 코드 받기 (최초 1회)
PowerShell을 열고 실행한다.
```
cd C:\Users\jwcho\workspaces\test-nlu
git remote add origin https://github.com/BobbyJO0411/test-nlu
git pull origin claude/project-thread-bo1al5
```
이미 origin이 있다는 메시지가 나오면 두 번째 줄은 건너뛴다.

## 2. 동작 확인
```
$env:PYTHONIOENCODING="utf-8"
..\nlu-venv\Scripts\python.exe -m unittest discover -s tests
```
- 마지막 줄에 OK가 나오면 정상이다.
- (선택) 웹 화면으로 모델을 직접 써 보기: `powershell -ExecutionPolicy Bypass -File scripts\start.ps1` 실행 후 브라우저에서 http://127.0.0.1:8000 접속, 질문을 입력하면 추천 후보 3개가 나온다. 끝낼 때는 PowerShell에서 Ctrl+C.

## 3. 시험 실행: 100건 추천과 평가지 생성
```
..\nlu-venv\Scripts\python.exe scripts\self_test.py prepare
```
- KoE5 모델로 질의 100건을 추천하고, artifacts\self_test\<실행ID>\ 폴더에 평가자A.xlsx, 평가자B.xlsx를 만든다. 약 1~2분 걸린다.
- 기본은 반자동 방식(후보 3개 중 평가자 선택)이다. 1순위만 평가하려면 끝에 `--mode top1`을 붙인다.
- 화면에 나온 실행ID와 폴더 경로를 적어 둔다. 아래 <실행폴더>는 이 경로이다.
- 실행 전에 코드나 데이터를 고쳤다면 먼저 커밋한다. 실행 기록에 ‘작업트리 변경 없음’이 남아야 한다.

## 4. 독립 평가
- 평가자A.xlsx는 A에게, 평가자B.xlsx는 B에게만 보낸다. 서로의 파일을 보여주지 않는다.
- 평가자는 ‘평가’ 시트의 100행을 모두 채운다: 설문 5개(1~5점), 판정(success/failure), 평가근거, 성명, 역할자격, 평가일시, 선택후보(1/2/3/없음).
- 돌려받은 파일은 <실행폴더>에 그대로 저장한다(파일 이름 유지).

## 5. 불일치 정리
```
..\nlu-venv\Scripts\python.exe scripts\self_test.py resolve --run-dir <실행폴더> --a <실행폴더>\평가자A.xlsx --b <실행폴더>\평가자B.xlsx
```
- 협의: <실행폴더>\협의결과.csv에 판정이 엇갈린 건만 나온다. A·B가 함께 검토해 final(success/failure), resolution_reason, resolution_date, participants를 채운다.
- 다수결: 끝에 `--decision-rule majority`를 붙이면 평가자C.xlsx가 만들어진다. C가 채운 뒤 같은 폴더에 저장한다.
- 불일치가 0건이면 이 단계는 확인만 하고 넘어간다.

## 6. 집계와 합격 판정
```
..\nlu-venv\Scripts\python.exe scripts\self_test.py score --run-dir <실행폴더> --a <실행폴더>\평가자A.xlsx --b <실행폴더>\평가자B.xlsx
```
- 다수결이면 끝에 `--decision-rule majority`를 붙인다.
- 화면에 적합도, 합의율, 판정(합격/불합격/판정 불가)이 나온다. 적합도 80% 이상이 합격이다.
- <실행폴더>에 시험결과서.docx, 시험결과_상세.xlsx, 시험결과.json, ratings.csv가 생긴다.
- 빈칸이나 형식 오류가 있으면 어느 건이 문제인지 알려 주고 멈춘다. 해당 평가자 파일을 고친 뒤 다시 실행한다.

## 7. 제출물
- 시험방법서.docx (artifacts\review_package)
- 시험결과서.docx (<실행폴더>)
