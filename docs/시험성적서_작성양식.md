## 측정 방법
고정된 고객 질의 100건을 대상으로 문장 임베딩을 수행하고 사전 등록된 템플릿 DB에서 응답 후보 상위 3개를 추출한다. 시험 대상으로 확정된 모드에 따라 추천 원문을 수집한다. 서로 독립된 실제 평가자가 각 추천을 검토하여 수정 없이 활용 가능한 경우를 성공, 수정이 필요한 경우를 실패로 판정한다. 최초 판정을 보존하고 불일치는 사전에 정한 규칙(협의 기록 또는 제3평가자 다수결)에 따라 최종 판정을 확정한다.

## 제한과 증빙
합성·공동 작성 초안을 사용했다면 실제 고객 분포와 독립 시험셋이라고 주장하지 않는다. 문자 baseline 결과는 E5/KoBERT 성능 결과로 사용하지 않는다. 모델 변경 또는 LLM 모드 전환 결과를 합산하지 않는다. 원문·후보·유사도와 정량 설문 원본, 승인서, 평가 서명, 협의 기록 및 실행환경 로그를 첨부한다. 기관이 발행하지 않은 결과를 인증 또는 ISO 적합 시험성적서로 표시하지 않는다.
