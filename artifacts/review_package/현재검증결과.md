- 실제 모델: intfloat/multilingual-e5-small, 384차원, CPU, 커밋 614241f622f53c4eeff9890bdc4f31cfecc418b3.
- 공식 Hugging Face 다운로드 파일의 SHA256 또는 Git blob SHA1을 대조한 뒤 로딩했으며, 보관된 로컬 모델의 해시도 다시 확인했다. 모델 가중치는 /workspace/nlu-model에 보관하고 Git에 포함하지 않는다.
- CPU 의존성 설치 및 pip check 통과. 동일 설치 스크립트를 재실행해 기존 모델 검증과 15개 자동 검증 모두 통과.
- 실제 서버에서 /health의 E5 모델 정보 확인 후 의견제출통지 질의의 T020 추천 원문·상위 후보·절차 설명 확인.

기대 템플릿은 공동 작성한 합성 초안의 레이블이다. 이 수치는 수정 없이 상담에 활용 가능한지 전문가가 판정한 결과가 아니고 독립 시험셋의 운영 성능도 아니다. 1순위가 틀린 32건을 숨기거나 제외하지 않았다. 현재 검색 품질은 추가 전문가 검토와 독립 데이터 검증·개선이 필요하다. 템플릿이나 모델을 개선할 때 현재 공개된 100건에 맞춰 최종 시험 성적을 주장하지 않는다.

최종 보관 실행은 artifacts/review_package/개발실행_manifest.json과 개발실행_recommendations.json에 기록된다. 구현 소스 해시, 질의·템플릿·모델·추천 원문 해시, 의존성과 플랫폼 정보를 함께 보관했다. Git 초기 커밋 전 실행은 git_commit=null일 수 있으므로 code_files_sha256로 당시 코드를 대조한다.

## 평가 파일과 자동 집계 검증
NLU_100건_평가데이터시트.xlsx, 평가자A_실평가.xlsx, 평가자B_실평가.xlsx와 DOCX 방법서·양식을 생성했다. 실제 평가자 판정은 모두 빈칸이다. 입력 누락·중복, 미해결 협의 및 추천 원문 변경을 거부하는 검증이 있다. 정량 설문 5항목의 평균·분포를 기록할 수 있다.

가상 A/B 자료는 모의 규칙 기반 예제이며 실제 실무자·변리사 판단이 아니다. 가상 적합도·합의율은 제출 불가로 표시하며 submission_candidate=false이다. 미평가 CSV의 적합도와 합의율은 null로 유지한다. 자동 집계는 서명·자격·실제 평가 사실의 진위를 인증하지 않는다.

## 미실행·미확정
- 실제 A/B의 독립 평가, 정답셋 사전 승인, 협의 및 서명: 미수행.
- 기관이 승인한 독립 홀드아웃 또는 운영 고객 분포의 재현: 미확정.
- 특정 E5-Ko 모델 요구에 다국어 E5가 허용되는지, ISO 지표 코드·산식 대응 및 합격 기준: 기관 확인 전.
- 기존 운영 제품 연결·자유 생성 응답 모드: 미구현·미검증 범위. 별도 추천 API와 후보 선택 어댑터를 제공한다.
- 옵션 OpenAI 실제 호출: 인증이 없어서 미실행. 인증 누락·후보 밖 선택 거부는 모의 API 테스트로 검증했다.
- 신규 클라우드 작업에서 스냅샷 복원: 아직 검증하지 않았다. 설치·시작 instructions와 모델 다운로드 도메인은 설정 초안으로 저장했고 게시 여부는 별도다.

## 네트워크 문제 조치
초기 모델 CDN 연결 403, Xet 캐시의 읽기 전용 경로 오류 및 다운로드 정체를 확인했다. 쓰기 가능한 /workspace 캐시, 공식 클라이언트의 HTTPS 다운로드 방식, 필요한 Hugging Face/CDN 허용 도메인 추가 후 실제 다운로드·해시 검증·E5 실행에 성공했다. TLS나 체크섬 검증을 비활성화하지 않았다. 실패 로그는 서명 URL 쿼리를 제거하고 남겼다.

## Git 배포 상태
main 브랜치에 전체 작업을 로컬 커밋했다. 원격 push는 GitHub HTTP 403으로 거부됐다: 현재 연결 계정 branvip0001-dev에 BobbyJO0411/test-nlu 쓰기 권한이 없다. 읽기 조회는 가능하며 별도 토큰 값은 요청하거나 저장하지 않았다. 해당 계정에 저장소 Write 권한을 부여하거나 쓰기 권한이 있는 계정으로 GitHub 연결을 변경한 후 push를 다시 실행해야 한다. 아직 원격 업로드 완료로 표시할 수 없다. 전체 자료 ZIP과 로컬 Git 이력을 포함한 test-nlu.bundle을 별도 제공한다.
