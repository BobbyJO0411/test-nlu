- 집계에 ISO/IEC 25023 FCr-1-G 형식 X = 1 − A/B를 함께 기록한다. 적합도와 같은 값이다.
- 실제 고객 질의 익명화·층화 추출, 정답 주석 병합, 승인 해시 출력 도구와 시험기관 확인요청서를 추가했다.
- 설치·실행 경로 하드코딩(/workspace)을 없애고 Windows용 PowerShell 스크립트를 추가했다. 실제 실행 검증은 Windows 11, Python 3.12.0, CPU에서 했다. Linux 스크립트는 구문 검사만 했고 Linux에서 다시 실행하지는 않았다.

- Windows 11 Home, Python 3.12, torch 2.5.1+cpu, requirements.lock.txt 고정 버전. pip check 통과.
- 모델 3종(KoE5, dragonkue/multilingual-e5-small-ko-v2, intfloat/multilingual-e5-small)의 모든 파일을 Hugging Face 공개 파일별 SHA256(LFS)·Git blob SHA1과 대조한 뒤 복사본을 만들었다. 검증 기록은 data/verified_models/에 있다.
- 이전 Linux 환경에서 받은 multilingual-e5-small의 파일 해시와 이번 Windows 다운로드 해시가 모두 같았다.
- dragonkue/multilingual-e5-small-ko-v2는 sentence-transformers 4.1.0으로 저장된 모델이라 3.4.1에서 버전 경고가 나온다. 비교용이며 기본 모델에는 해당하지 않는다.
- 자동 테스트 26개 통과(기존 15개 + 신규 11개: 개발셋·시험셋 중복 검사, 하이브리드 검색, 모델 해시 검증, 다수결 집계와 블라인드 C 파일 흐름, 실질의 익명화·층화 추출 등).

## 시험 질의 100건 검색 진단 — 사람이 측정한 응답 적합도가 아님
설정은 위 개발셋에서 먼저 정하고 커밋한 뒤 아래 실행을 했다. 아래 결과를 보고 설정을 바꾸지 않았다.

| 실행 | 기대 템플릿 Top1 | Top3 |
|---|---:|---:|
| **최종: KoE5 + hybrid(개발셋 선택)** | **82** | **97** |
| KoE5 본문 단독(모델만 교체) | 81 | 97 |
| KoE5 임베딩 단독 α=0.5, β=0(문자 점수 불허 시 대안) | 88 | 97 |
| dragonkue small-ko + hybrid | 80 | 94 |
| multilingual-e5-small + hybrid | 83 | 97 |
| 이전 기본값: multilingual-e5-small 본문 단독 | 68 | 91 |
| 문자 TF-IDF baseline | 65 | 84 |

- 이전 기본값 68/91과 baseline 65/84는 2026-10-14 Linux 결과와 똑같이 재현됐다.
- 최종 설정을 두 번 실행해 1순위 100/100 동일, 후보 점수 최대 차이 0.0. 질의당 지연시간 중앙값 약 0.46초, 95번째 0.53초(CPU, 초기 로딩 제외).
- KoE5 임베딩 단독(β=0)이 이 100건에서 더 높지만, 시험셋 결과를 보고 설정을 고르면 과적합이므로 채택하지 않았다. 기관이 문자 점수 결합을 허용하지 않을 때 개발셋 기준으로 쓸 대안이다.
- 개선 효과의 대부분은 템플릿 대표 질문 추가에서 나왔다(e5-small도 68→83). KoE5를 기본으로 둔 이유는 E5-Ko 요건과 개발셋 성능(67 대 63)이다.
- 최종 실행의 1순위 불일치 18건은 품질오인 2건 외에 유형별로 1건씩 흩어져 있다. 이 18건은 숨기거나 빼지 않았다.
- 이 100건은 템플릿과 함께 작성된 합성 초안이고 개발 과정에서 이미 공개됐다. 따라서 위 수치는 개발 검증이며, 최종 성적은 새로 수집·승인한 독립 질의로 산출해야 한다.
- 기대 템플릿 일치는 기계 진단이다. 사람이 ‘수정 없이 사용 가능’하다고 판정하는 적합도와 다르며, 1순위가 틀린 응답은 대부분 실패로 판정될 것이므로 적합도는 이 수치보다 높기 어렵다.

근거: artifacts/evidence/test100_retrieval_comparison.json. 실행 원본은 artifacts/runs/(Git 제외), 최종 실행은 artifacts/review_package/개발실행_manifest.json과 개발실행_recommendations.json에 보관했다.
